# Ilustrações conceituais das capas

Estas 13 ilustrações foram produzidas no Hermes, perfil `rescue`, com Banana Slides/Nano Banana e o modelo registrado em [`assets/decks/provenance.yml`](../../decks/provenance.yml).

- São metáforas visuais autorais para as capas; não representam telas ou resultados de produtos.
- A primeira geração foi rejeitada por conter texto. As versões publicadas foram editadas e revisadas para remover títulos, parágrafos, marcas e interfaces fictícias.
- Texto, código, legendas e fontes são adicionados como objetos nativos no PowerPoint.
- Os JPEGs publicados foram otimizados para 1920 px no maior lado, sem armazenar chaves, prompts privados ou configurações do Hermes.
- O curso não depende do Hermes nem de qualquer API de IA.

Hash, texto alternativo, episódio, projeto e versão de cada imagem estão registrados em [`assets/catalog.yml`](../../catalog.yml).
