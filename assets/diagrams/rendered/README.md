# Diagramas renderizados

Cada fonte Mermaid possui uma versão SVG para Markdown/apresentações e uma versão PNG de alta densidade para ferramentas que não preservam vetores. O fundo branco e a paleta Rescue Point mantêm o conteúdo legível tanto no tema claro quanto no escuro.

Para regenerar um ativo, use Mermaid CLI com `../mermaid-config.json` e revise visualmente o resultado antes de publicar.
