# Biblioteca visual

Os diagramas são autorais, baseados em fontes técnicas registradas na matriz de evidências. Arquivos Mermaid em `diagrams/source` são a fonte editável; `diagrams/rendered` contém SVG e PNG com fundo branco, legíveis nos temas claro e escuro. O mesmo conteúdo é incorporado nos Markdown para renderização nativa no GitHub.

Imagens oficiais só podem entrar em `official/` depois de confirmar permissão e registrar a licença em `catalog.yml`. Na dúvida, mantenha apenas o link para a documentação e produza um diagrama conceitual original.
