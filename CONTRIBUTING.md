# Como contribuir

Correções técnicas, melhorias de clareza e exemplos reproduzíveis são bem-vindos.

1. Abra uma issue descrevendo o problema ou a proposta.
2. Crie uma branch curta e focada.
3. Preserve a separação entre recursos open, gratuitos, pagos e preview.
4. Adicione uma fonte oficial à matriz de evidências quando introduzir um claim importante.
5. Execute as validações antes de abrir o pull request.

```bash
python scripts/verify_editorial.py
cd lab/dabdbt
./scripts/run_local.sh
```

Não inclua credenciais, identificadores cloud reais, dados privados ou código proprietário. Resultados de fornecedores devem ser descritos como reportados, nunca como resultado geral garantido.
