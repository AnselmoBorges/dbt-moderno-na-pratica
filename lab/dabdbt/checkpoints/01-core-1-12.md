# 01 — O conteúdo original e o baseline Core 1.12

Execute `python course.py checkpoint 01`. O checkpoint carrega seeds, cria a fixture de freshness, executa parse/build e valida `manifest.json`, `semantic_manifest.json`, `osi_document.json` e `run_results.json`.

Abra `lab/dabdbt/target/manifest.json` no explorador do editor ou, no Codespaces, use `code lab/dabdbt/target/manifest.json` a partir da raiz. Procure `parent_map` para ver dependências e `semantic_model.dabdbt.commerce_orders` para localizar a descrição semântica dos pedidos. O [manifest](https://docs.getdbt.com/reference/artifacts/manifest-json) registra o mapa do projeto. As linhas processadas ficam no DuckDB.

O checkpoint executa dbt Core 1.12.7. Consulte a [matriz oficial de recursos](https://docs.getdbt.com/docs/dbt/supported-features) para explorar o dbt v2.
