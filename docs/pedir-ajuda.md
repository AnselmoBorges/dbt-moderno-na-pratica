# Como pedir ajuda

Copie o modelo abaixo para uma issue. Substitua os campos entre colchetes e anexe `build/support-report.json`.

```text
Título: [sistema] Falha no checkpoint [NN]

Objetivo:
Comando executado:
Mensagem de erro completa:
O que já tentei:
O problema se repete? sim/não

Anexo: support-report.json
```

Não envie tokens, `.env`, hosts privados, `profiles.yml` corporativo, e-mail, usuário ou chave Gemini. O relatório do curso não coleta essas informações.
